## 📌 Overview

This project implements a **deep learning-based face recognition system** using **EfficientNet** as a feature extractor within a transfer learning framework.

The system learns discriminative facial embeddings and performs identity recognition from image input, emphasizing **deep feature extraction, model fine-tuning and inference workflow** rather than production deployment.

---

## 🎯 Objectives

- Build a real-time face recognition system using deep learning  
- Apply **EfficientNet** for facial feature extraction  
- Utilize transfer learning for improved performance  
- Evaluate recognition accuracy on unseen face data  

---

## 🧠 Model Used: EfficientNet

**EfficientNet** is a family of CNN models that:
- Scales network depth, width and resolution efficiently  
- Achieves high accuracy with fewer parameters  
- Performs well for transfer learning in vision tasks  

The pretrained EfficientNet model is fine-tuned for face recognition.

---

## 📂 Dataset

- Face images labeled by individual identities  
- Images are preprocessed through:
  - Face detection  
  - Resizing and normalization  
  - Data augmentation (where applicable)  

The dataset is used to train and evaluate the recognition model.

---

## ⚙️ Implementation Details

- **Language:** Python  
- **Framework:** Deep Learning (CNN-based)  
- **Model:** EfficientNet (transfer learning)  
- **Environment:** Jupyter Notebook  

Training setup typically includes:
- Loss Function: Categorical Cross-Entropy  
- Optimizer: Adam  
- Evaluation Metric: Accuracy

## 📈 Results

- The model successfully recognizes known faces in real-time scenarios  
- Demonstrates strong feature representation using EfficientNet  
- Outperforms classical face recognition methods on complex facial variations  

---

## 🧪 Key Learnings

- Practical application of transfer learning  
- Deep feature extraction for face recognition
